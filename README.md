# GUMYR — GUMIR.KZ

Ұлттық мәсі шеберханасының (GUMIR.KZ) корпоративтік сайты. Сегіз тілде (қазақша, орысша, ағылшынша, өзбекше, қырғызша, арабша, түрікше, қытайша; басқару панелінен жаңа тіл қосуға болады) қолжетімді, толығымен статикалық көп беттi лендинг.

## Іске қосу

```bash
node serve.mjs
```

Сайт `http://localhost:3000` мекенжайында ашылады.

## Скриншот алу

```bash
node screenshot.mjs http://localhost:3000 [label] [width] [height] [fullPage]
```

Скриншоттар `./temporary screenshots/` қалтасына сақталады.

## Құрылым

```
index.html              — негізгі бет (HTML + inline CSS)
assets/js/content.js     — сайттың бастапқы мазмұны мен 8 тілдегі аудармалар (CMS жұмыс істемесе, осы көрсетіледі)
assets/js/main.js        — интерактивтілік + CMS мазмұнын жүктеу (мәзір, тіл ауыстыру, каруселдер, форма)
cms/                     — басқару панелі (Vercel): API + интерфейс, қараңыз cms/README.md
assets/images/           — оңтайландырылған өнім/галерея фотолары
assets/video/            — қысқа процесс видеолары
scripts/optimize_images.py — фотоларды сығымдау скрипті (Pillow)
```
